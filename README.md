# Midnight Plots / graveslon

Пятибарабанный слот по методичке «Кладбище» для Stake Engine: 20 линий, 11 символов, бонус с сохраняющимися множителями могил ×2 → ×3 → ×5 → ×10.

**Статус: разработка. Не готов к реальным ставкам или отправке на ревью.**
Готовность каждого этапа и оставшиеся зависимости указаны в `docs/PROGRESS.md`.

## Содержимое

- `GDD.md` — полные правила, выплаты и принятые решения.
- `games/midnight_plots` — игра на официальном Math SDK, целочисленные расчёты, полосы барабанов.
- `games/midnight_plots/library/publish_files` — рассчитанный кандидат публикационного пакета (генерируется локально и в GitHub Actions).
- `tools/build_math.py` — воспроизводимый расчёт и калибровка весов.
- `tools/validate_math.py` — независимый пересчёт всех книг, событий и CSV.
- `reports/` — фактические показатели, SHA-256, номера контрольных исходов.
- `tests/fixtures.json.gz` — контрольные книги для будущего фронтенда.
- `docs/EVENTS.md` — контракт между математикой и интерфейсом.
- `assets/source` — восстановленные и новые исходники арта.
- `assets/runtime` — 59 игровых экспортов, включая символы, фоны, атласы персонажа, землю и UI.
- `assets/preview` — статичные макеты и проверка символов при 120 px.
- `docs/ART.md` — происхождение, сборка арта и передача в анимационный этап.
- `web/animation-lab` — локальный стенд проигрывания математических книг и анимаций.
- `docs/ANIMATION.md` — запуск стенда, проверки и границы этапа 4.
- `web/game` — игровой интерфейс с балансом DEMO, ставками, покупкой бонуса, настройками и правилами RU/EN.
- `web/shared/stage.mjs` — общий проигрыватель анимаций для интерфейса и QA-стенда.
- `docs/FRONTEND.md` — запуск интерфейса, демосессия, проверки и последующая интеграция RGS.
- `docs/GAME_FEEL.md` — текущая доработка вращения и показа выигрышей перед RGS.
- `docs/BONUS.md` — могилы, сложение множителей и бонусные переходы.
- `docs/MORTIMER.md` — послойный персонаж с постоянным тяжёлым дыханием и видео.
- `web/mortimer-lab` — крупный план дыхания персонажа.

## Сборка арта

```sh
python -m pip install -r requirements-art.txt
python tools/build_assets.py
python tools/validate_assets.py
```

Анимационный стенд запускается через `python -m http.server 8765`, затем открыть
`http://localhost:8765/web/animation-lab/`. Проверки событий:
`node --test tests/web/book-player.test.mjs`.
Игровой интерфейс доступен по пути `/web/game/` (или `/web/`). Он использует
учебные кредиты и явно обозначенный деморежим. Подключения RGS и реальных ставок пока нет.
Проверки интерфейса: `node --test tests/web/*.test.mjs` и
`node tools/verify_game_browser.cjs` при установленном Playwright/Chromium.

## Запуск (Python 3.12+ и Git)

```sh
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
python -m pip install -r requirements.txt
python tools/setup_sdk.py
python tools/sdk_smoke.py
python -m unittest discover -s tests -v
python tools/build_math.py --count 100000 --seed 20261020
python tools/validate_math.py
```

Можно указать `STAKE_MATH_SDK` вместо скачивания SDK; версия должна совпадать с `sdk.lock.json`. Генератор последовательный, не требует локальных сокетов multiprocessing. Исходники SDK не изменяются. Собственный калибратор максимальной энтропии заменяет необязательный Rust-оптимизатор: целые веса проверяются отдельным аудитом. Установка Rust не нужна.

Уменьшенный прогон `--count 1000` пригоден для smoke-проверки, но не заменяет полный прогон. Он перезаписывает кандидат, отчёты и фикстуры; перед релизом всегда выполнять полный расчёт и аудит заново. Не использовать сырой средний выигрыш симуляции как RTP: RTP считается по финальным весам всей библиотеки с учётом стоимости режима.

Фронтенд должен только проигрывать события RGS. Примерные исходы QA нельзя выдавать за распределение реальной игры. Секреты, sessionID, API-ключи и личные документы в репозиторий не добавлять.

## Публикационный пакет

Большие книги не хранятся в истории Git. Workflow `Math verification` пересоздаёт 200 000 исходов, проводит аудит и сохраняет artifact `midnight-plots-math-candidate` на 90 дней. Исходники, зафиксированные версии и seed позволяют восстановить пакет после истечения срока. Локально рассчитанный пакет содержит около 100 МБ.
