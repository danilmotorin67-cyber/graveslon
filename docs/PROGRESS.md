## Что проверяется локально

- Официальный fifty_fifty запускается последовательно и формирует книги/CSV/index.
- Код игры наследует официальный Math SDK; ядро SDK не изменено.
- 12 автоматических тестов: выплаты 3/4/5 для всех символов, wild, сложение могил,
  лестница и потолок множителей, ограничение общего выигрыша, сброс между раундами,
  повторяемость seed, сравнение 3000 случайных полей с независимым расчётом,
  контрольные книги и намеренно испорченные события.
- Полный независимый аудит проверяет все поля по полосам барабанов, выигрыши,
  события, индексы, триггеры, ретриггеры, завершение бонуса, cap и равенство книг/CSV.

## Границы готовности

Локальный PASS не является одобрением Stake Engine. Нет игровых sessionID,
проверок authenticate/play/end-round/replay в реальном RGS, финального provider ID,
заключений о названии и правах, подтверждения актуальных ограничений кабинета.
Не загружать кандидат на финальное ревью, пока остальные этапы не закрыты.
