## Сборка и проверка

```sh
python -m pip install -r requirements-art.txt
python tools/build_assets.py
python tools/validate_assets.py
```

Скрипт только уменьшает/масштабирует исходники, применяет вертикальный blur,
рендерит SVG и компонует готовые слои. Прозрачные изображения масштабируются
с premultiplied alpha. Оригиналы остаются неизменными. Экспортированные фоны
увеличены из исходных 1672×941 и 941×1672; это честный ресайз, не новая детализация.

`assets/manifest.json` содержит относительные пути, назначение, размеры, вес,
источник и SHA-256 каждого экспорта. Проверка останавливается при пропуске
ассета, нарушении соответствия 11 кодам GDD, отсутствии прозрачности,
неверном размере или изменении исходника. Отчёт — `reports/art-validation.json`.
Workflow `Art verification` повторяет сборку и проверку после разрешённого push.

## Передача в этап 4

По замечанию о парящих ногах добавлен отдельный слой земли с камнями и корнями
в стиле фона. Спрайты персонажа сохранены, их положение в стенде привязано
к подошвам. Под каждой позой используются контактные тени; idle-анимация больше
не поднимает персонажа. Промпт нового слоя — `assets/grounding-prompt-20261021.txt`,
исходник и SHA-256 включены в `assets/sources.json`.

1. Использовать `assets/manifest.json` как реестр путей; не переименовывать символы.
2. Вращение использует symbols_blur, остановка — symbols. Исходы берутся из книг.
3. Рамка имеет открытое окно x=64,y=64,w=1152,h=624: пять ячеек по 230,4 px
   и три по 208 px. Центры и размеры рассчитывать из окна, а не внешних углов.
4. Множители рисовать поверх ячеек по `graveMultiplierUpdate` из docs/EVENTS.md.
   Текст и реальные суммы выводить отдельно; не рассчитывать выигрыш из картинок.
5. bonus_entry/result — оформление. Число FS и итог берутся только из событий.
   Английские плашки уже готовы, для RU использовать отдельные локализованные
   надписи/векторные варианты при реализации интерфейса.
6. Следующий этап: отдельный стенд анимаций — вращение, anticipation, рост могил,
   линии, выигрыши, пропуск. Затем звук; доступ к платному ElevenLabs пока отсутствует.
